The goal

Wild Yough Glamping is a 5-hut glampground on 350 private acres along the Youghiogheny River in Oakland, MD. Third-party booking platforms charge fees and hide guest contact details, so the site is built to move guests to direct reservations on the business's own website.

How the quote calculator works

Check-in and check-out dates  +  one hut or full site
                 |
                 v
   For each night: Fri or Sat?  -> weekend rate
                   Sun to Thu?  -> mid-week rate
                 |
                 v
   Subtotal = sum of nightly rates
                 |
                 v
   + 6% Maryland sales tax  + 8% Garrett County lodging tax
                 |
                 v
   Total  ->  deposit due today

Code snippet: night-by-night pricing

A simplified version of the calculator's core logic. Each night is priced on its own, so a Thursday-to-Sunday stay mixes mid-week and weekend rates correctly.

// Simplified version of the quote logic (rates and deposit are placeholders)
const RATES = { weekday: 0, weekend: 0 };      // set per hut or full site
const MD_SALES_TAX = 0.06;
const GARRETT_LODGING_TAX = 0.08;
const DEPOSIT_RATE = 0.0;                        // share of total due at booking

function quote(checkIn, checkOut) {
  let subtotal = 0;
  for (let night = new Date(checkIn); night < checkOut; night.setDate(night.getDate() + 1)) {
    const day = night.getDay();                  // 0 = Sun ... 5 = Fri, 6 = Sat
    subtotal += (day === 5 || day === 6) ? RATES.weekend : RATES.weekday;
  }
  const taxes = subtotal * (MD_SALES_TAX + GARRETT_LODGING_TAX);
  const total = subtotal + taxes;
  return { subtotal, taxes, total, deposit: total * DEPOSIT_RATE };
}

Simplified for illustration; the live calculator also switches between single-hut and full-site rates.
