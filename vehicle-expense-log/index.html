The problem

Mileage, fuel and meal receipts were tracked inconsistently, which made tax-time deductions and job costing slow and error-prone.

How it works

        |  POST
        v
Google Apps Script web app

        v
Google Sheet  ->  summaries / charts
  • Front end: a static HTML/CSS/JavaScript form hosted on Netlify, built for phones.
  • Back end: a Google Apps Script web app receives each entry and appends a row.
  • Data store: a Google Sheet with one row per trip or expense, ready for pivot tables and reporting.

Features

  • Log trips (purpose, miles), fuel purchases and meals.
  • Timestamped, structured records for filtering by date, category or job.
  • No server or database costs.

Skills demonstrated

  • Data collection design: clean, consistent input produces clean data
  • Apps Script automation and API-style integration
  • Spreadsheet data modeling and reporting

The live app writes to a private business sheet, so it is not linked here.
