Code snippet: quote form validation

A simplified example of how the form checks a request before it is sent. Every request arrives with the same fields filled in, which is what makes the leads usable as data.

// Simplified example of the quote form's validation pattern
const form = document.querySelector("#quote-form");
const message = document.querySelector("#form-message");

form.addEventListener("submit", (event) => {
  const required = ["name", "email", "service", "level"];
  const missing = required.filter((field) => !form.elements[field].value.trim());

  if (missing.length > 0) {
    event.preventDefault();                       // stop the send
    message.textContent = "Please fill in: " + missing.join(", ");
    message.className = "error";
    return;
  }
  message.textContent = "Thanks! We'll be in touch with your quote.";
  message.className = "success";
});

Simplified for illustration; field names are examples.
