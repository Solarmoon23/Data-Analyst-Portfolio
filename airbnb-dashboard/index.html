Key findings

QuestionFindingWhat it means
SizeAverage nightly price rises with every bedroom: $96 (1) → $175 (2) → $250 (3) → $315 (4) → $450 (5) → $585 (6).Bedroom count is the clearest price driver in the data.
Value per bedroomPrice per bedroom dips from $96 for 1-bedroom listings to $79 for 4-bedroom homes, then climbs back to $98 at 6 bedrooms.3–4 bedroom homes are the best value per bedroom for groups.
Supply1-bedroom listings are 70% of supply (1,811 of 2,580); only 80 listings (3%) have 4 or more bedrooms.Large-group homes are a small niche of the market.
LocationZIP 98119 (Queen Anne) has the highest average price at about $200 a night, roughly 3× the lowest-priced ZIP codes.Location adds a clear premium; the map shows where it sits.
SeasonThe weekly total of calendar prices climbs from about $1.0M in early January to about $1.9M by late spring, then holds near that level for the rest of 2016.Most of the year's potential revenue sits from spring onward.

Method

  1. Data: Seattle Airbnb open data for 2016: a listings table (price, ZIP code, bedrooms) and a calendar table (nightly prices by date).
  2. Build: one Tableau worksheet per question, using averages for price, a distinct count for listings and a weekly sum of calendar prices.
  3. Design: combined the five views into one dashboard, with matching ZIP code colors so the bar chart and the map read together.
  4. Publish: shared on Tableau Public, where viewers can hover over any chart for details.

Limitations: the "revenue" line sums listed calendar prices, so it shows potential revenue, not confirmed bookings. Averages can be pulled up by a few luxury listings, and the data covers Seattle in 2016 only.
