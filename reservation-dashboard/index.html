The problem

Bookings came in through several platforms (Airbnb, Booking.com, Hipcamp and direct), each with its own calendar. The owners had no single place to see occupancy, upcoming arrivals or revenue, and tracking happened in a spreadsheet that had to be updated by hand.

 Dashboard: timeline, occupancy, records

What I built

  • Live iCal integration: pulls each channel's calendar feed and merges them into one reservation timeline.
  • Occupancy view: booked vs. open nights per unit.
  • Editable reservation records: add, edit and delete reservations and nightly rates in the page, synced for all viewers through a live database.
  • Multi-property design: the Pine & Paw version served as the reference model; the Wild Yough Glamping version extends it to five individual huts.

Skills demonstrated

  • Data integration from multiple external sources (iCal / ICS parsing)
  • Data cleaning and de-duplication across booking channels
  • Dashboard design for non-technical stakeholders
  • JavaScript, HTML, CSS

The live dashboard uses private calendar links and real guest data, so it is not linked here.
